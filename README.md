# 테더링 지킴이

사무실 테더링용 갤럭시 노트9의 상태를 **문자로** 확인하는 앱입니다. 데이터를 쓰지 않습니다.

## 할 수 있는 것

| 내가 보내는 문자 | 폰이 하는 일 |
|---|---|
| `#상태` (설정에서 바꿀 수 있음) | 지금 상태를 답장 |
| `#알림끔` / `#알림켬` | 자동 알림 끄기 / 켜기 |
| `#도움` | 명령 목록 답장 |

등록한 번호에서 온 문자에만 답합니다. 다른 번호는 무시하고 기록에만 남깁니다.

### 답장 예시

```
핫스팟ON 연결3 LTE3/4 인터넷OK 87%충전중 38C 12.3/50GB 가동5일
```

| 항목 | 뜻 |
|---|---|
| 핫스팟ON / OFF | 핫스팟이 켜져 있는지 |
| 연결3 | 연결된 기기 수 (안드로이드가 막으면 안 나옴) |
| LTE3/4 | 통신망과 신호 세기 (4칸 중 3칸). 망없음, 비행기모드, 유심오류도 표시 |
| 데이터OFF | 모바일 데이터가 꺼졌을 때만 표시 |
| 인터넷OK / X | 폰의 모바일 인터넷이 실제로 되는지 |
| 87%충전중 / 충전X | 배터리와 충전기 연결 |
| 38C | 배터리 온도. 45도 이상이면 "과열" 표시 |
| 12.3/50GB | 이번 달 데이터 사용량 / 설정한 제공량 |
| 가동5일 | 마지막 재부팅 후 지난 시간 |

단문 한도(70자, 90바이트) 안에 맞추고, 길어지면 가동시간 → 연결 수 → 데이터 순으로 뺍니다.

### 자동 알림 (첫 번째 등록 번호로)

1분마다 확인해서 아래 상황이면 문자를 보냅니다. 하루 최대 20건입니다.

- 핫스팟이 2분 넘게 꺼짐 / 다시 켜짐
- 인터넷이 3분 넘게 끊김 / 복구 (끊긴 시간 포함)
- 충전기 빠짐 / 다시 연결
- 배터리 온도 45도 이상 / 42도 아래로 회복
- 충전 안 되는 상태에서 배터리 20% 이하
- 데이터 제공량 90% 도달 (한 달에 한 번)
- 폰 재부팅 (켜지고 2분 뒤, 그때 상태와 함께)

예: `[핫스팟꺼짐] 핫스팟OFF LTE3/4 인터넷OK 87%충전중 38C 12.3/50GB`

## APK 만들기

둘 중 편한 방법 하나를 고르세요.

### 방법 A. GitHub에서 자동으로 만들기 (설치할 것 없음, 추천)

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository** → 이름 `TetherWatch`, **Private** 선택 → **Create repository**.
3. 만들어진 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 `TetherWatch` 폴더 **안의 내용 전체**를 끌어다 놓고 **Commit changes**를 누릅니다.
   - `.github` 폴더는 숨김 폴더라 안 보일 수 있습니다. 안 올라갔으면 **Add file → Create new file**에서 이름을 `.github/workflows/build.yml`로 하고 이 폴더의 같은 파일 내용을 붙여 넣으세요.
5. 위쪽 **Actions** 탭에서 "APK 빌드"가 초록 체크가 될 때까지 기다립니다 (5분 정도).
6. 저장소 첫 화면 오른쪽 **Releases → 최신 APK**에서 `TetherWatch.apk`를 받을 수 있습니다.
   노트9의 인터넷 브라우저로 GitHub에 로그인하면 폰에서 바로 받을 수 있습니다.

코드를 고쳐서 다시 올리면 APK도 자동으로 새로 만들어집니다.

### 방법 B. 컴퓨터에서 Android Studio로 만들기

1. https://developer.android.com/studio 에서 Android Studio를 설치합니다.
2. **Open**으로 `TetherWatch` 폴더를 엽니다. 처음엔 필요한 파일을 내려받느라 몇 분 걸립니다.
3. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. 완료 알림의 **locate**를 누르면 `app-release.apk` 또는 `app-debug.apk`가 있습니다.
5. 이 파일을 카카오톡 "나와의 채팅", USB, 구글 드라이브 등으로 노트9에 옮깁니다.

## 노트9에 설치하고 설정하기

1. 노트9에서 APK를 누릅니다. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켭니다.
   Play 프로텍트 경고가 나오면 **무시하고 설치** (직접 만든 앱이라 나오는 경고입니다).
2. **테더링 지킴이**를 열고 위에서부터 차례로 누릅니다.
   - **문자·전화 상태 권한 허용** → 모두 허용
   - **데이터 사용량 접근 허용** → 목록에서 "테더링 지킴이"를 켜고 뒤로
   - **배터리 최적화에서 제외** → 허용
   - 네 줄이 모두 `[O]`가 되면 됩니다.
3. 조회할 번호(내 폰 번호)를 넣고, 필요하면 키워드와 데이터 제공량을 넣은 뒤 **저장**.
4. **첫 번째 번호로 테스트 문자 보내기**로 문자가 오는지 확인합니다.
5. 내 폰에서 노트9로 `#상태`를 보내 답장이 오는지 확인합니다.

### 노트9에서 꼭 바꿔둘 설정

- **설정 → 연결 → 모바일 핫스팟 및 테더링 → 모바일 핫스팟 → ⋮ → 고급(또는 설정)**
  → "연결된 기기가 없을 때 핫스팟 끄기"(타임아웃)를 **사용 안 함**으로.
- **설정 → 디바이스 케어 → 배터리 → 백그라운드 사용 제한**
  → "사용하지 않는 앱을 절전 상태로 전환" 끄기, 또는 "절전 예외 앱"에 테더링 지킴이 추가.
- **설정 → 디바이스 케어 → 배터리 → 추가 배터리 설정 → 배터리 보호** 켜기 (85%까지만 충전, 24시간 충전 시 배터리 부풀음 예방).
- **설정 → 디바이스 케어 → 자동 최적화 → 자동 재시작** 끄기 (원하지 않는 재부팅 방지). 켜두면 재부팅될 때마다 "[재부팅됨]" 알림이 옵니다.

알림창에 "테더링 지킴이 작동 중"이 항상 떠 있어야 정상입니다. 지우지 마세요.

## 알아두기

- **연결 기기 수**는 안드로이드 10이 막아둘 수 있어서 안 나올 수 있습니다. 나머지 항목은 영향이 없습니다.
- **데이터 사용량**은 폰이 센 값이라 통신사 계산과 조금 다를 수 있습니다. 테더링으로 쓴 데이터도 포함됩니다.
- **원격으로 핫스팟 켜기**는 안드로이드가 일반 앱에 허용하지 않아 넣지 않았습니다. 핫스팟이 꺼졌다는 알림이 오면 사무실에서 직접 켜야 합니다.
- 문제가 5가지 이상 동시에 생기는 드문 경우에만 문자가 2건으로 나뉠 수 있습니다.
- 서명 키(`app/tetherwatch.jks`)는 지우지 마세요. 같은 키여야 새 버전을 덮어 설치할 수 있습니다. 저장소는 **Private**으로 두세요.

## 파일 구성

```
app/src/main/java/kr/tetherwatch/
  MainActivity.java     설정 화면
  SmsReceiver.java      문자 명령 받기 → 답장
  MonitorService.java   1분마다 확인, 자동 알림
  StatusCollector.java  핫스팟·통신·배터리·데이터 읽기
  Status.java           답장 문자 만들기 (단문 길이 맞춤)
  SmsSender.java        문자 보내기
  BootReceiver.java     재부팅 후 자동 시작
  Prefs.java            설정·기록 저장
.github/workflows/build.yml   GitHub 자동 빌드
```
